The AI Nervous System: Full Masterclass Guide

الجهاز العصبي للذكاء الاصطناعي: الدليل الشامل

This document is a complete bilingual representation of how to build an Autonomous Machine, based on "Artificial Intelligence: A Modern Approach" (AIMA) - Chapter 2.

هذا المستند هو تمثيل كامل ثنائي اللغة لكيفية بناء آلة مستقلة، بناءً على كتاب "الذكاء الاصطناعي: مقاربة حديثة" - الفصل الثاني.

1. What is an Intelligent Agent?

1. ما هو الوكيل الذكي؟

English: An Intelligent Agent is any system that can perceive its environment, make decisions, and take actions to maximize its success. It is not just a script; it is a "living" mathematical loop.

Formula:
Action = Brain(Sensor(Environment))
العربية: الوكيل الذكي هو أي نظام يمكنه إدراك بيئته، اتخاذ القرارات، واتخاذ الإجراءات لزيادة نجاحه إلى أقصى حد. إنه ليس مجرد كود برمجي؛ بل هو حلقة رياضية "حية".

المعادلة:
الإجراء = الدماغ(المستشعر(البيئة))

2. Phase 1: Sensors & Perception

2. المرحلة 1: المستشعرات والإدراك

English: A machine cannot think if it cannot see. A Sensor is the "Eye" of the machine. The data it captures is called a Percept.
  • In hardware: A thermometer, a camera, or a microphone.
  • In software: Reading an API (like Facebook Views) or reading a database.
Key Logic: The sensor must have Memory to detect Changes (Delta) over time (Time t vs Time t-1).
العربية: الآلة لا تستطيع التفكير إذا كانت لا تستطيع الرؤية. المستشعر (Sensor) هو "عين" الآلة. البيانات التي يلتقطها تسمى الإدراك (Percept).
  • في الأجهزة: مقياس حرارة، كاميرا، أو ميكروفون.
  • في البرمجيات: قراءة واجهة برمجة التطبيقات (مثل مشاهدات فيسبوك) أو قراءة قاعدة بيانات.
المنطق الأساسي: يجب أن يحتوي المستشعر على ذاكرة (Memory) لاكتشاف التغييرات بمرور الوقت (الوقت t مقابل الوقت t-1).

3. Phase 2: The Agent Function / Brain

3. المرحلة 2: دالة الوكيل / الدماغ

English: The "Brain" is just a mathematical mapping. It takes the Percept (Input) and maps it to an Action (Output). This is written as the function A(T).

If T (Temperature) is a Scalar (single number like 72), the brain uses simple logic:
  • if (T > 72) return "COOL"
If T is a Vector (multiple numbers like [72, 45, 1]), the brain uses complex logic to process multiple variables.

Example 2: A Vector (Two Sensors)
If the machine has a Temperature sensor and a Humidity sensor, the input becomes a Vector array: V = [Temperature, Humidity].
Example: V = [75, 80] (75°F and 80% Humidity).
The Brain logic becomes multi-dimensional:
  • if (V[0] > 72 AND V[1] > 60) return "TURN_ON_DEHUMIDIFIER"
العربية: "الدماغ" هو مجرد تعيين رياضي (Mathematical Mapping). يأخذ الإدراك (المدخلات) ويحوله إلى إجراء (المخرجات). تُكتب هذه الدالة كـ A(T).

إذا كانت T (الحرارة) قيمة مفردة (Scalar) (رقم واحد مثل 72)، يستخدم الدماغ منطقاً بسيطاً:
  • if (T > 72) return "COOL"
إذا كانت T متجهاً (Vector) (عدة أرقام مثل [72, 45, 1])، يستخدم الدماغ منطقاً معقداً لمعالجة عدة متغيرات.

المثال الثاني: المتجه (مستشعران)
إذا كان الروبوت يمتلك مستشعر حرارة ومستشعر رطوبة، يصبح المدخل مصفوفة متجهة: V = [الحرارة، الرطوبة].
مثال: V = [75, 80] (75 درجة فهرنهايت و 80% رطوبة).
يصبح منطق الدماغ متعدد الأبعاد:
  • if (V[0] > 72 AND V[1] > 60) return "TURN_ON_DEHUMIDIFIER"

4. Phase 3: Actuators & Motor System

4. المرحلة 3: المشغلات والنظام الحركي

English: If a machine only has sensors, it is paralyzed. It needs Actuators to physically alter the universe around it.
  • In hardware: A robotic arm, a wheel, or an electrical Relay switch turning on the AC.
  • In software: Writing a file to a hard drive, sending a Discord message, or executing a stock trade.
العربية: إذا كانت الآلة تمتلك مستشعرات فقط، فهي مشلولة. تحتاج إلى مشغلات (Actuators) لتغيير الكون من حولها فيزيائياً.
  • في الأجهزة: ذراع آلي، عجلة، أو مفتاح كهربائي (Relay) لتشغيل التكييف.
  • في البرمجيات: كتابة ملف على القرص الصلب، إرسال رسالة على ديسكورد، أو تنفيذ صفقة أسهم.

5. Phase 4: The Event Loop

5. المرحلة 4: حلقة الحدث

English: A nervous system never sleeps. The Event Loop is the heartbeat (the Clock). Computers operate in Discrete Time (ticks). We use tools like setInterval to force the machine to constantly repeat the cycle:
  1. Breathe in (Perceive)
  2. Think (Decide)
  3. Breathe out (Act)
العربية: الجهاز العصبي لا ينام أبداً. حلقة الحدث (Event Loop) هي نبض القلب (الساعة). تعمل أجهزة الكمبيوتر في وقت متقطع (Discrete Time) (نبضات). نستخدم أدوات مثل setInterval لإجبار الآلة على تكرار الدورة باستمرار:
  1. شهيق (إدراك)
  2. تفكير (اتخاذ قرار)
  3. زفير (تنفيذ إجراء)

6. How to Connect Hardware to Software

6. كيفية ربط الأجهزة بالبرمجيات

English: To bridge the gap between the physical and digital world:
  1. Sensors (Thermistor): Senses physical heat as an electrical voltage.
  2. Translation (Microcontroller like Arduino): Converts electrical voltage into a digital number (ADC - Analog to Digital Converter).
  3. Communication: Sends the number to Node.js via Serial Cable (USB) or Wi-Fi.
  4. Action (Actuator): Node.js calculates the decision and sends an electrical signal back to the Arduino to flick a physical Relay switch.
العربية: لسد الفجوة بين العالم المادي والرقمي:
  1. المستشعرات (Thermistor): يستشعر الحرارة الفيزيائية كجهد كهربائي.
  2. الترجمة (متحكم دقيق مثل Arduino): يحول الجهد الكهربائي إلى رقم (ADC - محول تناظري إلى رقمي).
  3. الاتصال: يرسل الرقم إلى Node.js عبر كابل USB أو Wi-Fi.
  4. التنفيذ (Actuator): يحسب Node.js القرار ويرسل إشارة كهربائية مرة أخرى إلى الأردوينو لتشغيل مفتاح كهربائي فعلي (Relay).
